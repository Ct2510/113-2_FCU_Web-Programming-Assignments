# Classic Popcat Click｜點擊互動練習

## 專案簡介

以貓咪張嘴／閉嘴圖片與音效練習瀏覽器事件處理。這是本機前端小作品，不是官方 POPCAT 服務。

## 開發目的

以按下／放開的即時回饋，練習指標、鍵盤、畫面狀態與瀏覽器音效之間的整合。

## 核心功能與完成範圍

| 項目 | 說明 |
| --- | --- |
| 按壓互動 | 指標或鍵盤按下時張嘴，放開後恢復圖片。 |
| 音效回饋 | 使用者互動後播放並輪替音效。 |
| 點擊計數 | 畫面更新計數；事件重複與持久化問題仍待修正。 |

## 技術實作

| 技術／模組 | 用途 |
| --- | --- |
| 事件處理 | pointer 與 keyboard 事件驅動畫面狀態。 |
| 圖片／音效切換 | 整合 imgs 與 pops 目錄中的素材。 |
| 資料保存 | 目前 Cookie 輔助程式未完成，不能當成已實作持久保存。 |

## 操作方式

- 指標按下或鍵盤按下時切換張嘴圖片，放開後恢復。
- 點擊計數與輪替音效；瀏覽器音效需要使用者互動後才可能播放。
- 沒有伺服器排行榜、帳號或跨裝置同步。

## 本機預覽

下載專案後，於專案根目錄執行（需 Python 3）：

```bash
git clone https://github.com/Ct2510/113-2_FCU_Web-Programming-Assignments.git
cd 113-2_FCU_Web-Programming-Assignments/assignments/classic-popcat-click-1134
python -m http.server 8080 --bind 127.0.0.1
```

開啟 <http://127.0.0.1:8080/>；以 `Ctrl+C` 停止。此命令只提供靜態檔案，不是應用程式後端。連接埠被佔用時可將 `8080` 改為 `8081`。
