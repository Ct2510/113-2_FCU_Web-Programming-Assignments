# Snake｜原生 JavaScript 貪食蛇

## 專案簡介

以 DOM 網格製作的小型遊戲，練習方向輸入、遊戲迴圈、狀態管理與碰撞判斷。

## 開發目的

用小型遊戲將方向輸入、狀態更新、碰撞與分數串成完整操作迴圈，練習拆解前端互動規則。

## 核心功能與完成範圍

| 項目 | 說明 |
| --- | --- |
| 網格遊戲 | 以 30 × 30 棋盤呈現蛇、食物與移動結果。 |
| 方向控制 | 方向鍵操作，禁止直接反向。 |
| 穿越邊界 | 離開一側後由另一側出現；不是撞牆結束。 |
| 分數與難度 | 吃食物加分並加快速度，撞到自身則結束。 |
| 流程控制 | 提供開始、重新開始、暫停與繼續。 |

## 技術實作

| 技術／模組 | 用途 |
| --- | --- |
| DOM 與 CSS | 以網格元素呈現棋盤與遊戲狀態。 |
| JavaScript 狀態 | 維護蛇身、方向、食物、分數與執行狀態。 |
| 事件與更新迴圈 | 由方向鍵與操作按鈕影響定期更新的遊戲畫面。 |

### 專案資訊

| 項目 | 說明 |

## 操作方式與遊戲規則

- 使用方向鍵控制，不能直接反向。
- 跨越棋盤邊界會從另一邊出現，**不是撞牆結束**。
- 吃到食物增加分數並加快速度；碰到身體則結束。
- 提供開始／重新開始及暫停／繼續控制。

## 本機預覽

下載專案後，於專案根目錄執行（需 Python 3）：

```bash
git clone https://github.com/Ct2510/113-2_FCU_Web-Programming-Assignments.git
cd 113-2_FCU_Web-Programming-Assignments/assignments/Snake
python -m http.server 8080 --bind 127.0.0.1
```

開啟 <http://127.0.0.1:8080/>；以 `Ctrl+C` 停止。此命令只提供靜態檔案，不是應用程式後端。連接埠被佔用時可將 `8080` 改為 `8081`。

## 測試與驗證狀態

沒有自動測試；本次未進行瀏覽器驗收。可手動確認方向鍵、禁止反向、穿越邊界、吃食物、撞身體、暫停與重新開始。

## 限制與下一步

食物位置目前未排除蛇身所在格；尚無填滿棋盤的勝利處理、觸控操作、最高分保存或多人模式。可先將移動與碰撞抽成可測試邏輯，再補隨機食物位置與手機操作。
