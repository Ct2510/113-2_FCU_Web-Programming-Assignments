# Bouncing Balls｜Canvas 動畫練習

## 專案簡介

以物件管理球體位置、速度與顏色，練習 Canvas 繪圖、動畫迴圈與碰撞判斷。

## 開發目的

以畫面中持續移動的球體練習動畫更新流程，將物件狀態、繪圖與碰撞規則連接起來。

## 核心功能與完成範圍

| 項目 | 說明 |
| --- | --- |
| 隨機球體 | 建立 25 顆球，隨機設定大小、顏色與速度。 |
| 邊界反彈 | 球體接觸畫布邊界後反向移動。 |
| 碰撞變色 | 偵測球體接觸並改變顏色，不是完整物理碰撞模擬。 |
| 動畫軌跡 | 持續更新 Canvas，透過半透明覆蓋保留移動痕跡。 |

## 技術實作

| 技術／模組 | 用途 |
| --- | --- |
| 物件狀態 | 以 Ball 類別保存位置、速度、大小與顏色。 |
| Canvas 2D | 將每顆球的狀態轉為畫面中的圓形。 |
| requestAnimationFrame | 在瀏覽器動畫迴圈中更新狀態與繪製。 |

## 動畫規則

- 產生 25 顆隨機大小、速度與顏色的球。
- 遇畫布邊界反向；球體相碰時改變顏色。
- 使用 `requestAnimationFrame` 更新畫面，半透明覆蓋形成軌跡。

碰撞變色不是動量守恆的彈性碰撞模擬；目前沒有控制面板、分數或資料保存。

## 本機預覽

下載專案後，於專案根目錄執行（需 Python 3）：

```bash
git clone https://github.com/Ct2510/113-2_FCU_Web-Programming-Assignments.git
cd 113-2_FCU_Web-Programming-Assignments/assignments/bouncing_balls
python -m http.server 8080 --bind 127.0.0.1
```

開啟 <http://127.0.0.1:8080/>；以 `Ctrl+C` 停止。此命令只提供靜態檔案，不是應用程式後端。連接埠被佔用時可將 `8080` 改為 `8081`。
