# Waiting Page｜載入動畫與音樂互動頁

## 專案簡介

以前端動畫、進度顯示與音樂播放控制練習等待頁。頁面使用 TETR.IO 相關風格與文字，**不是官方網站，也未與官方服務串接**。

## 開發目的

為等待情境設計視覺與聲音回饋，練習動畫狀態切換與使用者控制音樂；目前進度是模擬值，不是實際下載任務。

## 核心功能與完成範圍

| 項目 | 說明 |
| --- | --- |
| 載入動畫 | 呈現約五秒的模擬進度與歡迎狀態。 |
| 音樂控制 | 使用者可播放／暫停背景音樂。 |
| 視覺素材整合 | 結合背景、字型與動畫營造等待頁氛圍。 |

## 互動方式

- 約五秒的模擬載入進度與動畫／歡迎狀態。
- 背景音樂播放與暫停；瀏覽器通常需要使用者手勢才能播放。
- **進度並未連到真實下載或工作佇列**，不代表網路任務完成比例。

## 本機預覽

下載專案後，於專案根目錄執行（需 Python 3）：

```bash
git clone https://github.com/Ct2510/113-2_FCU_Web-Programming-Assignments.git
cd 113-2_FCU_Web-Programming-Assignments/assignments/waiting_page
python -m http.server 8080 --bind 127.0.0.1
```

開啟 <http://127.0.0.1:8080/>；以 `Ctrl+C` 停止。此命令只提供靜態檔案，不是應用程式後端。連接埠被佔用時可將 `8080` 改為 `8081`。

不需先執行 `npm install` 或 `node index.js`。Google Fonts 等遠端資源需要網路。

## 測試與目前限制

- 原始碼引用 `sounds/click.mp3` 與 `sounds/error.mp3`，但 Repository 沒有 `sounds/`，相關音效無法完整載入。
- [package.json](package.json) 的 `npm test` 是預設失敗占位，不是自動測試套件。
- 本次未執行瀏覽器驗收；可手動檢查進度切換、播放／暫停、靜音或拒絕播放時的行為，以及主控台缺少檔案的錯誤。
